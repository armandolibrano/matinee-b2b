# Matinee B2B — Portale Agenti

Applicazione B2B per la rete agenti di MATINEE (Ocean Style S.r.l.).
Interfaccia in un unico file `index.html`, dati su Supabase (PostgreSQL + Auth).

- Login: username + password (Supabase Auth)
- Ruoli: amministrazione, direttore commerciale, agente
- Catalogo, carrello, ordini, PDF conferma d'ordine, export Excel gestionale, scorte

Sviluppato da [librano.it](https://librano.it) — assistenza: contact@librano.it
